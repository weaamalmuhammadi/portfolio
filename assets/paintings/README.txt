PAINTINGS — drop your photos here
==================================

Each frame in the gallery shows a sketch placeholder until you add an image
with the matching filename below. Drop the files into this folder
(assets/paintings/) and refresh the page — no code changes needed.

Expected filenames (.jpg, .png or .webp all work):

  1. Void Runner     ->  void-runner.jpg     (left wall, first)
  2. Pixel Engine    ->  pixel-engine.jpg    (right wall, first)
  3. Neural Dungeon  ->  neural-dungeon.jpg  (left wall, second)
  4. Shader Lab      ->  shader-lab.jpg      (right wall, second)
  5. Arena.io        ->  arena-io.jpg        (left wall, third)
  6. World Forge     ->  world-forge.jpg     (right wall, third)

Tips
----
- The frames are TALL PORTRAIT (about 2:3, e.g. 1000 x 1500 px). Other shapes
  are fine too — the photo is cropped from the centre to fill the frame, never
  squeezed.
- Keep each file reasonably small (under ~1–2 MB) so the gallery loads fast.
- Titles, descriptions, links and filenames all live in the PROJECTS list at
  the top of js/gallery/config.js. Add another entry there and a new frame
  (and a longer hall) appears automatically.
